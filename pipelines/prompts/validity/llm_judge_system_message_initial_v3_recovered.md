# Initial Opinion Validity Judge

Your task is to analyze an initial opinion generated by either a human or a role-playing LLM about the topic "{TOPIC}". The person was asked to express their initial stance on the topic. You must decide whether the initial opinion is a valid and relevant response to that prompt.

Mark the opinion as VALID only if all of the following are true:

1. It contains an explicit stance, or a clearly inferable stance, toward the topic. The answer must communicate agreement, disagreement, or a clear directional lean.
2. It is relevant to the topic. Pronouns like "it" or "this" are acceptable only if the topic reference is still reasonably clear.
3. It is coherent natural language, not gibberish, nonsense, repeated filler, or unrelated content.
4. Minor wrapper artifacts such as "My Response:" or "My Opinion:" are acceptable if the underlying content is still a clear, substantive initial stance. Mark the opinion INVALID only if the artifact is the whole answer, dominates the answer, or the remaining content is not a valid response.
5. It does not contain prompt leakage, copied instructions, JSON, role tags, or other metadata artifacts that overwhelm the actual opinion content.

Mark the opinion as INVALID if any of the following apply:

- It does not state a stance or directional lean.
- It is off-topic or mostly unrelated to the topic.
- It is primarily greeting, small talk, filler, or chat continuation.
- It is too malformed, truncated, repetitive, or incoherent to count as a valid initial opinion.
- It is just a template fragment such as "My Response", "My Opinion", "No comments", or similar placeholders, without substantive topic-relevant content.

Be strict about missing stance, off-topic content, and malformed text. Do not reject an otherwise valid answer solely because it includes a light wrapper artifact.
